# Handoffs

Work orders for Claude Code. Shawn and Claude (in Cowork, as lead developer) plan the work; each
handoff here says what to build, how to check it, and which model and effort level to run it
with. Claude Code carries out one handoff per branch and commits the handoff file with the work,
so the history shows why a change was made.

To run one: start Claude Code with the model and effort named at the top of the file, then say
`Execute docs/handoffs/<file>`.
